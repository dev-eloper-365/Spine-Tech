## Brand
- Name: Spine Tech
- Offer: solutions for every type of hardware or software problem that companies and agencies have.
- Strengths: skilled with AI; has worked with many organizations; connects organizations together
  to execute concrete workflows.
- Central idea: "the spine" — one backbone that connects systems, teams and organizations.
- Visual motif idea: a vertical spine / network line that links nodes.

## Decisions (made 2026-11-08)
- Priority 1: match the reference layout/motion/feel as closely as possible. Priority 2: lightweight.
- Stack: Vite + plain TypeScript, Lenis (smooth scroll), OGL (tiny WebGL lib). No framework.
- Display font: Respira Black (Sharp Type), file supplied by user: public/fonts/Respira-Black.woff2 (Latin subset, 67 KB). User is responsible for the web license. Body: Inter Variable.
- Brand assets: none given yet. Original SVG art is generated by `scripts/gen-art.mjs`.
- Hero title text is "Spine / Technologies" (2 lines like the reference) — confirm with user.

Live reference: https://www.ryanritzenthaler.com/ (reviewed 2026-11-08 in Chrome).

Mood: white bg, black type, huge display type, one 4-point star glyph used as a brand mark everywhere,

Order of sections, with the component type in each:
1. Sticky header: star logo left; nav links (text swaps on hover, word duplicated); black pill CTA "Inquire →".
2. Rotating circular text badge ("spinner") with star in the middle, top-right of hero.
3. Hero: name in huge display type over 2 lines; short intro paragraph bottom-left.
4. WebGL hero object: a star-shaped image plane, distorted/glitch shader, iridescent edge, moves on scroll;
   big faded grey display text behind it ("…is … thing!?").
5. Intro split: tall image collage left (3 panels); display heading + 2 short paragraphs right.
6. Marquee band: huge italic sans words with star separators, infinite horizontal scroll, thin rules.
7. Services: display heading left + short paragraph right; then full-screen sticky stacked cards,
   one per service (bg = project screenshot, dark overlay), each with title, 1-line text, pill tags,
   "Reach out ✦" link. 4 services.
8. Featured work: display heading + rotating "SCROLL" circular badge; Card View / List View toggle;
   2-column grid of project cards (image, tech pill tags, "Completed: <date>", name →).
9. Footer: big display "Let's Build!" + rotating spinner badge; 3 link columns (Work / Learn / Reach Out).
10. End scene: black WebGL space scene with a glowing animated sun + stars, display text
    "Thanks for making it this far!" above/below.
Global: custom cursor (small black dot), Lenis smooth scroll, Awwwards ribbon (do not copy).

### 2026-11-09 — Liquid title: reference method (cursor disc)
- Studied the reference bundle (saved files): its fluid is a stable-fluids sim in the style of mnmxmx "fluid-three".
  Values used: resolution 0.25 of the viewport, cursor_size 40 cells (soft disc, strength (1-r)^2*1.5, additive),
  mouse_force 120 (diff/7), viscous 4 with 8 Jacobi iterations, poisson 16 iterations, vorticity 0, dt 0.016,
  advection vel*2.55 and *0.98 decay, divergence dt*8, fixed walls (quad shrunk by one cell).
- Reference title = opaque PNG (black text on white), data-rgb → "rgbSample": R from uv-off, G center, B from uv+off;
  uv -= vel*0.5/aspect, off = vel*0.1. Sim covers the full window; the title reads velocity at its screen position.
- src/gl/title.ts rewritten with these values (own code, OGL). Text canvas is now opaque white, no padding.
- Cursor dot is 18px (reference: 90px white box, clip-path circle(10%), difference blend).
